# Криптиране на диска и хардуерни ключове

Инсталираният Swissman държи root дяла криптиран с LUKS2 (Argon2id). При
стартиране initramfs-ът отключва диска, преди да пусне системата.

## Начини за отключване

- **Парола.** Винаги я има и остава резерва, ако загубиш ключа.
- **FIDO2 USB ключ** (YubiKey, SoloKey, Nitrokey, Token2 и други). Ключът
  пази тайна, без която дискът не се отключва. По желание иска PIN и докосване.
- **FIDO2 ключ с пръстов отпечатък** (YubiKey Bio, Token2 Bio, Feitian BioPass
  и подобни). Пръстът се проверява в самия ключ, затова работи на всеки
  компютър.

Вграденият четец на пръстови отпечатъци на лаптоп не може да отключи диска
сигурно: той само казва „да“ или „не“ и не пази тайна, от която да се изведе
ключът на диска. Затова Swissman използва FIDO2 ключове.

Ако ключът е записан, при стартиране initramfs-ът чака ключа до около 25
секунди. Без ключ пита за паролата.

## Записване на ключ

Пъхни ключа и изпълни като root (`/dev/nvme0n1p2` е криптираният дял):

```sh
# Сложи PIN на нов ключ (веднъж за ключа)
fido2-token -L
fido2-token -S /dev/hidraw0

# Ключ с PIN и докосване
systemd-cryptenroll --fido2-device=auto /dev/nvme0n1p2

# Ключ с пръстов отпечатък: пръстът замества PIN-а
systemd-cryptenroll --fido2-device=auto --fido2-with-client-pin=no \
  --fido2-with-user-verification=yes /dev/nvme0n1p2
```

Командата пита за текущата парола на диска. Запиши и втори ключ като резерва,
като повториш командата с него.

Провери какво е записано:

```sh
systemd-cryptenroll /dev/nvme0n1p2
```

Махни загубен ключ (паролата и останалите ключове остават):

```sh
systemd-cryptenroll --wipe-slot=fido2 /dev/nvme0n1p2
```

Не трий паролата (`--wipe-slot=password`), освен ако имаш поне два
работещи ключа.

## Как се тества

CI създава криптиран диск, записва в него софтуерен FIDO2 ключ
(`tests/virtual-fido2.py`) и стартира системата в QEMU два пъти: с ключа
дискът се отключва без парола, без ключа се отключва с паролата.
